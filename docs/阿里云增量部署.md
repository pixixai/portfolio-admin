# 阿里云增量部署与失效文件清理

适用于阿里云轻量应用服务器＋宝塔＋Nginx。后台在本机编辑和构建，通过SSH/SFTP更新服务器现有的网站目录；不需要将整个管理后台上传服务器。仅公开静态站不需要云端Node.js；启用私密空间时需另外配置轻量访问服务，见[分享空间操作与部署](分享空间.md)。

## 1. 首次准备

1. 在宝塔创建纯静态网站，确认根目录，例如`/www/wwwroot/pixixai.com`。
2. 确认阿里云防火墙允许你使用的SSH端口，默认`22`，并准备服务器SSH用户名及密码，或SSH私钥。
   - SSH连接信息与宝塔网页面板的账号、密码、端口不同。
   - 当前服务器需提供Python3与SFTP。阿里云Linux服务器通常已有这两项；可在宝塔终端执行`python3 --version`确认Python3。
   - 本功能只更新文件，不更改防火墙、DNS、HTTPS或宝塔站点启停状态。首次ICP备案尚未通过时，继续保持之前的网站关闭和公网端口限制。
3. 更新后台代码及依赖，关闭旧后台窗口，再启动`启动后台.cmd`。
   - 从GitHub更新代码后，在项目目录执行`npm ci`安装新增依赖。本机运行此功能只需Node.js；Python3运行在服务器端。

## 2. 在本地发布需要展示的内容

1. 编辑作品或展示设置，保存草稿。
2. 点击右上角「发布」，勾选需要发布的作品及网站设置，点击「确认发布」。
3. 在「发布完成」面板点击「增量部署到阿里云」。
   - 也可打开「发布」，点击「部署已发布网站」，直接部署当前本地发布版本。
   - 部署使用已经构建好的完整展示站，包含当前所有已发布作品，不会直接上传未发布草稿。
   - 原来的ZIP导出继续保留；腾讯Pages、阿里ESA Pages仍使用各自的部署包流程。这里的SSH部署针对轻量服务器／自管服务器。

## 3. 配置服务器并检查差异

1. 填写服务器公网IP或SSH域名、SSH端口、用户名和网站目录。
   - 默认用户名`root`、端口`22`；若服务器使用其他账户或端口，以实际配置为准。
   - 网站目录必须已经存在，只填写作品站专用目录。不能选择`/`、`/www`、`/www/wwwroot`等系统或站点父目录。
2. 首次连接点击「获取指纹」，与服务器SSH主机指纹核对。
   - 可在阿里云控制台远程连接或宝塔终端中执行以下只读命令，查看服务器各类SSH公钥指纹；界面取得的`SHA256:…`应与其中一项一致：
     ```sh
     for key in /etc/ssh/ssh_host_*_key.pub; do ssh-keygen -lf "$key" -E sha256; done
     ```
   - 点击「检查差异」会信任所显示的指纹，并保存该服务器连接信息。之后主机指纹不一致时拒绝连接，不会继续发送凭据；更换服务器或重装系统后需重新核对。
3. 选择「SSH密码」并输入密码，或选择「SSH私钥」并选取私钥文件；加密私钥同时填写口令。
   - 密码、私钥及口令只在本次连接／部署过程中使用，不保存到数据库、配置文件或部署包。关闭面板、刷新页面或下次启动后需要重新输入；部署成功后自动清空输入框。
   - 非敏感连接信息与服务器指纹保存在本机`user`数据中，不提交GitHub。
4. 点击「检查差异」，等待服务器比对文件。
   - 在服务器端计算SHA-256，不把线上图片视频下载回本机。
   - 面板显示需要上传、可以复用、成功后将清理的文件数量和本次上传体积，可展开查看文件名。
   - 首次接管已经手动部署的网站时，内容相同的文件也会复用。只接管本版本清单中的文件；以前手动上传的ZIP、备份或其他未知文件不会自动删除。
   - 修改连接信息后须重新检查。检查结果超过30分钟，或线上文件发生变化时，也须重新检查。

## 4. 执行增量部署

1. 核对差异列表和目标网站目录，点击「部署并清理失效文件」。
2. 保持本机后台命令行运行，等待完成。
   - 先通过SFTP上传变化文件到网站目录之外的临时区，再验证内容哈希和大小。
   - 相同文件不重复传输；新增媒体先就位，入口页面最后更新。
   - 更新成功并验证完整新站点后，才清理旧清单中已经不再使用的文件。
   - 上传失败、校验失败或检查结果过期时，不更新正在展示的网站。激活过程中失败会尝试恢复原文件；进程意外中断时，下次连接会先恢复未完成事务，再检查差异。
   - 若更新已提交但网络返回丢失，后台会重新连接检查任务结果；无法确认时明确提示重新检查，不把不确定结果显示为成功。
3. 完成后查看上传、复用和清理数量，再检查网站展示效果。
   - 本功能不自动开启网站。已备案并开站的网站可刷新查看；尚未备案的网站仍按原部署文档等待开站。
   - 成功更新后不长期保留整站备份；本功能没有新增云端历史版本保留或回退界面。

## 5. 清理边界与磁盘占用

- 清理对象只来自本工具上次成功部署的清单，且已从本次完整新站点清单中移除。当前版本仍使用的媒体、正文、封面和恢复描述文件都会保留。
- 未接管的文件、宝塔`.user.ini`／`.htaccess`、证书验证`.well-known`目录及其他未知文件不自动清理。已被外部修改的旧文件也会保留并在检查结果中说明。
- 拒绝目录穿越与符号链接路径；不递归清空网站根目录。仅删除已经成功清理文件留下的空目录。
- 私有部署清单、临时上传和事务备份保存在网站根目录的同级隐藏目录`.portfolio-admin-sync/<站点标识>/`，不放到作品站公开目录。
- 成功部署后删除临时媒体与事务备份，只留下少量清单和任务结果；未完成且未激活的上传，后续连接时会清理超过24小时的临时任务。清理失败会保留状态并在后续连接重试。
- 本次只实现增量传输和失效文件清理。本机发布历史仍按原有5／10条规则管理；仍在展示的作品本身会随数量增加占用存储。
