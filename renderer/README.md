# 作品站生成模板

这是后台管理系统使用的独立展示模板。编辑后的作品及网站设置以后台数据库为准，由发布流程生成新的部署包。

## 默认内容

- 署名、网站名称与页脚使用“噼哩画啦”。
- 首页默认视频：`assets/home/home-background.mp4`，播放速度1倍，黑色蒙板80%，默认循环播放，不设置结束定格图。
- 两个示例作品分别位于 `Portfolio/调色盘 · 示例作品/` 和 `Portfolio/棱镜 · 示例作品/`，各含一张独立封面和一张正文图。
- 默认保留品牌 / IP、包装设计、UI / UX、平面视觉、空间设计、电商视觉六个标签。
- 手机与桌面端共用首页、作品瀑布流、分类吸顶、作品详情浮层和图片放大功能。

## 独立构建

在本目录安装依赖后执行：

```powershell
npm ci
npm run build
npm run check
npm test
```

构建输出为 `dist/`，其中 `index.html` 位于部署根目录。构建产物不提交到代码仓库。通过后台发布导出的部署包还会带有可恢复的编辑数据；仅手动运行模板构建不生成后台恢复描述。

`site.json`、`index.html` 与 `Portfolio/` 用于新安装初始化。修改它们不会覆盖已经初始化的后台数据库；后续作品通过后台编辑或部署包导入维护。
