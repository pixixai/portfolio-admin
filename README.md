# 后台管理系统

独立于原「作品集网站」的本机个人作品管理工具。界面沿用浅蓝、淡紫、弥散渐变与玻璃质感；编辑、上传、预览和发布均使用自己的数据及展示副本，不覆盖原作品集网站文件夹。

本文记录当前已经实现并确认的功能，作为后续开发、调整和验收的依据。最后更新：2026-10-26。

## 1. 打开与启动

已安装依赖时，双击本目录的 `启动后台.cmd`，或在本目录执行：

```powershell
npm start
```

打开 [后台管理](http://127.0.0.1:4180/) 直接进入作品管理，无需创建账号或登录。已移除登录页、账号设置、修改密码与退出入口；启动时自动清理旧账号记录和登录会话表，作品、素材、草稿、网站设置与发布记录保留。

后台仅供本机使用，默认监听 `127.0.0.1`。请求还会校验本机连接、访问地址及端口；管理接口、预览和历史页面拒绝跨来源读取，写入接口继续校验请求来源。只认可 `127.0.0.1`、`localhost` 或IPv6本机地址，不接受其他域名指向本机的访问。不提供远程管理和多用户账号。

需要 Node.js 24，或22.13及以上版本。换电脑或尚未安装依赖时，先执行 `npm ci`。启动窗口需要保持运行，关闭服务后网页不能保存或生成预览。首次初始化会导入 `renderer` 自带的作品及图片，此后以后台数据库中的内容为准。

### 1.1 默认版本与首次初始化

当前代码以默认示例版本交付，换电脑使用空数据目录启动时自动得到相同内容：

- 两个已发布示例：「调色盘 · 示例作品」「棱镜 · 示例作品」。每个作品包含独立封面与一张正文图，封面按原图匹配16:9。
- 六个默认标签：品牌 / IP、包装设计、UI / UX、平面视觉、空间设计、电商视觉。
- 首页默认视频为 `renderer/assets/home/home-background.mp4`，由指定的首页视频复制并改名，1倍速、80%黑色蒙板，结束保留最后一帧。
- 默认姓名、网站标题与页脚署名使用“噼哩画啦”；发布历史默认保留10条。
- 模板已移除旧作品、简历提取文件及旧版迁移脚本，不会在新安装时恢复旧的个人作品集。

已有数据目录不会随代码更新自动清空；初始化以 `imported` 标记区分。完整旧数据备份应保留在代码仓库之外。

### 1.2 左上角名称编辑

左上角图标旁的名称读取网站设置中的 `brand`，默认“噼哩画啦”。双击进入输入状态，右侧显示对号；点击对号、点击空白处失焦或按Enter完成保存，Esc取消。空输入恢复原名称，支持1～50个字符；保存失败保留输入并显示错误。

名称单独保存为设置草稿，刷新与重启后保留，网站发布时随设置一起导出；不会改写姓名或覆盖设置页其他尚未保存的输入。键盘可聚焦名称后按Enter或F2编辑。

### 1.3 GitHub提交范围

以整个 `portfolio-admin` 目录作为独立仓库即可，前台生成模板已包含在 `renderer/`，不需要原作品站同级目录才能启动。提交源代码、锁定依赖、README与两组示例图片及默认视频。依赖目录、生成输出、数据库、运行数据、缓存与日志已加入忽略规则；不把本机数据备份或旧作品站放入仓库。

`npm run check`在原项目环境核对旧站完整性；单独下载后台代码、没有旧作品站同级目录时，会明确跳过该项，继续进行代码和图标检查。

## 2.「编辑作品」页面功能说明

### 2.1 页面结构与打开、关闭

- 从作品管理点击「新建作品」或编辑现有作品，在作品列表上方打开编辑浮层，底部保留原页面并叠加黑色遮罩。
- 点击浮层两侧空白、右上角关闭按钮，或在没有其他待处理交互时按 Esc，可退出编辑；退出前等待草稿保存。
- Esc 优先取消当前拖动、关闭块类型菜单或标签菜单、退出当前选区，再按当前界面的规则处理退出编辑。
- 左侧为文档式编辑区，自上而下是作品标题、标签、简介、正文。
- 标题就是作品名称；标签统一合并原来的「作品分类」和「内容标签」，不在右侧重复设置。
- 标签从作品管理中维护的已有标签读取，可多选、搜索，也可创建新标签，最多30个。
- 右侧为同一个设置面板，上方是作品封面，下方是页面预览。
- 打开编辑器时光标位于作品标题。界面提供窄屏布局。

### 2.2 正文块与输入提示

正文采用类似 Notion 的轻量块编辑方式，每个段落或媒体都是独立块，可单独选择、转换、删除和排序。新作品默认包含一个空文字块，单个作品最多300个内容块。

| 块类型 | 已实现的内容 |
| --- | --- |
| 文字 | 正文、一至三级标题、引用、无序列表、有序列表、待办、代码、分割线 |
| 图片 | 适配正文宽度，保留原图，可更换或删除 |
| 视频 | 适配正文宽度，使用浏览器原生播放器 |
| 音频 | 使用浏览器原生播放器 |
| 表格 | 独立表格块，可编辑单元格、操作行列和设置标题行／列 |

空文字块平时保持空白，仅在光标进入文字编辑区或鼠标悬停该块时，显示「输入文字，或输入 / 选择类型」。提示只用于界面，不写入正文。

媒体不使用每块独立的说明边框。悬停图片、视频或音频时，左上角显示文件名，右上角显示更换、删除按钮。

### 2.3 添加块与回车规则

正文顶部工具栏提供「图片、视频、音频、表格、在上方插入、在下方插入」。工具栏在编辑区向下滚动时吸顶，位于保存／发布标题栏下方。

| 操作 | 结果 |
| --- | --- |
| 普通文字中按 Enter | 在下一位置创建独立文字块，按光标拆分前后内容 |
| Shift+Enter | 在当前块内换行，不创建新块 |
| 列表或待办中按 Enter | 创建同类型的下一个独立块 |
| 空列表项或空待办中按 Enter | 退出列表／待办，改为普通文字 |
| 代码块内按 Enter | 在代码块内部换行 |
| 表格单元格内按 Enter | 留在表格单元格内编辑 |
| Ctrl/Cmd+Enter | 在当前块之后插入普通文字块，可用于退出代码块等类型 |
| 作品标题中按 Enter | 在正文最开头插入普通文字块 |
| 选中图片、视频、音频后按 Enter | 在该媒体下方插入普通文字块 |
| 点击文章末尾空白处 | 继续输入；末尾已有空文字块时优先聚焦它 |
| 点击两个已有块之间的空隙 | 不创建新块 |
| 点击「在上方插入／在下方插入」 | 在光标所在块或选中块的对应一侧插入文字块 |

没有可用的定位块时，「在上方插入」添加到正文开头，「在下方插入」添加到正文末尾。

通过工具栏添加媒体时，文字光标位于块内则在光标位置插入，并保留两端文字及行内格式；当前是整块选中状态时，在所选定位块之后插入，避免使用之前遗留的文字光标拆开其他块。

### 2.4 Markdown即时输入与行内格式

文字输入 Markdown 标记后会即时显示对应样式，底层仍保存为 Markdown。

| 在段落开头输入 | 转换为 |
| --- | --- |
| `#` + 空格 | 一级标题 |
| `##` + 空格 | 二级标题 |
| `###` + 空格 | 三级标题 |
| `-`、`*` 或 `+` + 空格 | 无序列表 |
| `1.` + 空格，也兼容 `.` + 空格 | 有序列表 |
| `[]` 或 `[ ]` + 空格 | 待办复选框 |
| `---`，也兼容 `—-` | 分割线 |
| 三个连续反引号 | 代码块 |
| `>` + 空格 | 引用 |

| 行内写法 | 效果 |
| --- | --- |
| `**文字**` | 加粗 |
| `*文字*` 或 `_文字_` | 斜体 |
| 单反引号包围文字 | 行内代码 |
| `~文字~` 或 `~~文字~~` | 删除线 |
| `++文字++` | 下划线 |

输入结束标记后自动应用行内格式。Ctrl/Cmd+B、I、U分别切换加粗、斜体、下划线，可用于选中文字，也可用于后续输入。

列表中的每一项都是独立块。有序列表自动续号，排序或删除后重新编号。待办的复选框与文字首行同行，后续行在文字区域内换行；回车创建的新待办默认未勾选。

代码块右上角提供复制按钮，只复制代码正文，保留空格、缩进和换行，不包含 Markdown 围栏或语言名称，复制成功后显示短暂反馈。

### 2.5 光标、选择与全选

| 操作 | 选择规则 |
| --- | --- |
| 鼠标上下拖动 | 可跨块选择内容，靠近编辑区上下边缘时自动滚动 |
| Ctrl/Cmd+点击其他块 | 不连续加选，再次点击已选块可取消该块的选择 |
| Shift+点击文字位置 | 从原光标位置精确选到目标字符，可跨块，包含中间内容 |
| 点击手柄后，Shift+点击另一手柄 | 连选两个块及中间所有块 |
| Ctrl/Cmd+A，当前块只有光标或部分文字选区 | 先选中当前块内全部内容 |
| Ctrl/Cmd+A，当前块已经整块选中或文字已全选 | 直接选中全部正文，不要求连续按键 |
| Ctrl/Cmd+A，当前块为空 | 一次直接选中全部正文 |

「全部正文」指正文中的块，不包含作品标题、标签和简介。

选区支持复制、剪切、粘贴、删除和输入替换。跨块删除会保留两端未选中的文字与行内格式；Tab／Shift+Tab可调整所有选中块的缩进。

选中外观采用以下规则：

- 整块选中时，在块范围内显示半透明浅蓝色覆盖层，不使用超出块边界的描边。
- 图片、视频、音频同样在内容上方叠加浅蓝色覆盖层，避免背景填充被媒体遮住。
- 部分文字选区仅高亮选中的字符。
- 多选或全选不会让所有手柄常显，只有鼠标悬停的块显示手柄；手柄自身获得键盘焦点时也可见。
- 方向键或 Esc 可返回光标／单块选中状态。

### 2.6 六点手柄、单块与成组拖动

六点手柄的定位规则：单行或多行文字与第一行文字水平居中；图片、视频、音频等媒体块靠左上角。

- 点击手柄，选中整块并打开块类型菜单。
- 从手柄拖动超过少量距离后开始排序，其他块平滑让位；鼠标停留在左侧空隙也能调整位置。
- 靠近编辑区上下边缘时自动滚动，支持鼠标、触控笔和触屏的手柄拖动。
- 多选后拖动任意已选中块的手柄，会将所有选中块作为一组移动。
- Ctrl 加选的不连续块也可一起移动，组内始终保留正文中的原有先后顺序，不按点击选择的顺序排列。
- 拖动未选中块，只移动该块；拖动已选中图片的手柄不会把多选缩减为一张图片。
- 成组拖动时预览提示块数量，完成后保留选中状态，可继续操作。
- 选中全部正文时，没有组外的放置目标，顺序保持不变。
- 按 Esc 取消本次拖动，恢复原顺序与选区。
- 聚焦手柄后按 Alt+上下方向键可调整位置，与原生拖放共用成组排序逻辑。
- 新顺序可保存，重新打开后保持一致。

### 2.7 缩进、转换与删除

**缩进**：Tab将当前块或所有选中块向右缩进，Shift+Tab向左缩进，最多六级。文字和媒体均支持。缩进写入草稿，并用于预览、发布和源文件导出；普通文字缩进不会误变成 Markdown 代码块。

**切换类型**：在空文字块输入 `/`，或点击六点手柄，打开类型菜单。支持正文、标题、列表、待办、引用、代码、分割线、图片、视频、音频、表格。

- 文字转换为其他文字格式时保留内容；空块转换为标题、列表等类型时也保留目标类型。
- 文字转换为表格时，将原文字放入首个单元格。
- 转换为图片、视频、音频时，打开素材选择面板。
- 无法放进目标类型的内容保留为相邻块。例如分割线不能容纳原文字，媒体不能直接变成文字内容，均保留原内容，避免静默丢弃。

**删除**：整块选中后按 Backspace或Delete可删除所选块；文字编辑中的退格与删除仍按文本编辑处理。

- 图片、视频、音频下方有空文字块，光标位于该空块时按 Backspace或Delete，会删除空块并选中上方媒体。
- 删除后将焦点转移到相邻内容；删除全部块后保留一个空文字块，可继续输入。
- 表格行列选中与整块选中分开处理。

### 2.8 块间距、空白与滚动稳定性

| 相邻组合 | 编辑区间距规则 |
| --- | --- |
| 文字 ↔ 图片 | 两个方向增加12px |
| 文字 ↔ 视频 | 两个方向增加12px |
| 文字 ↔ 音频 | 两个方向增加12px |
| 文字 ↔ 表格 | 两个方向增加12px |
| 文字 ↔ 文字 | 保持原间距 |
| 图片、视频、音频、表格相互相邻 | 保持原间距；连续图片直接相接 |

新增或转换块时，先完成富文本挂载及标题、简介的高度计算，再恢复编辑区的滚动位置。图片在加载前根据原始宽高预留空间，编辑区关闭浏览器自动滚动锚定，避免末尾回车、转换类型后视图意外上跳。只有新光标越过吸顶工具栏或屏幕底边时，才最小幅度滚动编辑区使它可见。

### 2.9 表格块

新表格默认是完全空白的 **3×3普通单元格**，没有默认标题行／标题列，不填入「列1、列2……」。整个表格也可作为一个块参与选择、缩进、拖动和删除。

**边缘加减行列**：

- 鼠标悬停表格时，右侧和底部出现「+」。
- 单击右侧「+」添加一列，单击底部「+」添加一行。
- 向右／向下拖动，可批量增加列／行。
- 反向向左／向上拖动，可批量缩减末端空列／空行。
- 反向缩减遇到包含内容的单元格就停止，并显示边界提示；至少保留一行、一列。
- 批量拖动按 Esc可取消，完成后可一步撤销。

**行列手柄及菜单**：

- 悬停单元格时，该列顶部、该行左侧出现短线，悬停短线后变为六点手柄。
- 点击手柄选中整行／整列并打开菜单；拖动可更改行列位置。
- 行列选中使用蓝色边框，拖动使用放置位置提示线。
- 行菜单提供上方插入、下方插入、复制、清除内容、删除；列菜单对应左侧插入、右侧插入。
- 菜单中的明确删除操作可以删除含有内容的行列，与反向缩减的空内容保护分开。

**标题行／标题列**：

- 行菜单最上方的「标题行」开关控制最上方一行。
- 列菜单最上方的「标题列」开关控制最左侧一列。
- 两个开关独立，可同时开启或关闭。
- 切换只改变单元格类型及样式，保留已有文字和格式；空单元格仍为空，不自动生成列名。
- 调整顺序后，标题样式保持在首行／首列。
- 保存重开、预览、发布及导出均保留标题设置和实际行列数，不额外插入空表头。
- 旧版自动填入列名、但正文完全为空的默认表格在编辑时兼容清理；有真实内容的表格保留内容。

### 2.10 作品封面与比例裁切

右侧封面区域的布局：

1. 标题「作品封面」，右侧以文字显示当前比例。
2. 点击封面预览，直接打开「封面比例与裁切」。
3. 封面下方依次放置「选择封面」按钮和「使用内容首图」开关。

「选择封面」打开图片上传／素材选择面板，选定图片后进入裁切窗口，应用后才切换为独立封面；取消不会改变原封面或首图模式。没有可用图片时封面预览不能裁切，可通过下方按钮选择图片。

支持七种比例：**16:9、3:2、4:3、1:1、3:4、2:3、9:16**。没有手动指定比例时，按图片宽高匹配最接近的比例。

「使用内容首图」的规则：

- 开启后跟随正文第一张图片；调整正文图片顺序后，封面来源也随之变化。
- 首图模式下仍可独立设置封面比例和取景区域。
- 关闭后回到之前的独立封面；原本没有独立封面时，将当前首图保留为可更换的独立封面。
- 开启和关闭开关都保留当前显示比例；原本为自动比例时，也固定为切换前的显示比例，避免跳回16:9等其他比例。
- 切换到不同图片时重置取景，同一张图片保留取景参数。
- 没有正文图片时保留首图模式，等待添加图片，不生成失效裁切。

裁切窗口的规则：

- 上方选择比例，中间为裁切预览。
- 鼠标滚轮以鼠标位置为中心缩放，范围1～4倍；拖动图片调整取景。
- 不显示独立的缩放滑杆或数值区域。
- 「重置」按钮居中放在裁切预览正下方。
- 「应用封面」才将临时调整写入草稿，取消不修改原设置。
- 裁切不修改原始文件及正文图片；后台缩略图、预览和新发布的展示站使用相同裁切参数。

### 2.11 媒体暂存与素材库

在编辑器内上传的媒体属于当前作品的暂存媒体，随草稿保留，仅当前作品可选，不会立即出现在公共素材库中。

发布成功后，作品实际使用的封面、图片、视频和音频才会入库；未使用的暂存文件、仅生成预览或发布失败的媒体不会因此入库。在素材库主动上传则立即入库，已入库的相同文件会去重复用。

支持的文件：

| 类型 | 格式 | 单项大小上限 |
| --- | --- | --- |
| 图片 | WebP、PNG、JPEG、GIF | 30 MB |
| 视频 | MP4、WebM | 200 MB |
| 音频 | MP3、WAV、OGG、M4A等已支持音频类型 | 200 MB |

媒体保留原文件，不做自动压缩或转码。音视频使用浏览器原生播放器，支持范围读取及拖动播放进度；能否播放取决于浏览器对具体编码的支持。

### 2.12 保存草稿、预览与发布

正文和属性修改后约1.2秒自动保存，也可点击「保存草稿」或按 Ctrl/Cmd+S手动保存，不触发浏览器保存网页。

手动保存的反馈直接显示在按钮上：

| 状态 | 按钮表现 |
| --- | --- |
| 保存中 | 旋转图标与「保存中…」，避免重复提交 |
| 保存成功 | 浅绿色「已保存」，约1.8秒后恢复「保存草稿」 |
| 没有新修改 | 同样显示成功反馈，不重复写入 |
| 保存过程中又有编辑 | 提示「有新修改」，避免将尚未保存的内容提示为全部已保存 |
| 保存失败 | 显示「保存失败」，保留具体错误提示，允许重试 |

成功后不再弹出右下角提示。重复快捷键共用当前保存请求；按钮状态在编辑器重新渲染时保留，关闭或切换作品后清理。

右侧「页面预览」使用一个统一按钮：首次为「预览」，生成后为「刷新预览」。点击先保存草稿，再生成与展示站一致的真实页面。可切换电脑／手机宽度，或新窗口打开；内容变化后会提示刷新，草稿预览仅在本机后台提供。

「发布作品」将当前草稿复制到已发布版本，不删除可编辑内容。发布后作品归入「已发布」，不再出现在仅未发布作品的「草稿」筛选中。后续编辑继续写入草稿并显示「有未发布修改」，访客仍看到上次发布的版本，直到再次发布。

### 2.13 常用快捷键汇总

Windows使用Ctrl，Mac使用Cmd对应相关组合键。

| 快捷键 | 功能 |
| --- | --- |

| Ctrl/Cmd+A | 当前块全选／正文全选；空块或已全选的块直接全选正文 |
| Ctrl/Cmd+B、I、U | 加粗、斜体、下划线 |

| Tab／Shift+Tab | 当前块或选中块缩进／取消缩进 |
| Backspace／Delete | 文本删除或删除所选块；媒体下方空块删除后选中上方媒体 |

## 3. 其他管理页面

- **作品管理**：新建、编辑、复制作品；数量整合在「全部作品·数量、已发布·数量、草稿·数量、待更新·数量」筛选标签内，不再单独占用统计区域。「待更新」指已有发布版本且草稿发生修改的作品，也计入已发布数量。
- **作品排序**：新建或复制的作品默认放在最前面；编辑已有作品不会改变排序。列表通过左侧手柄拖动，缩略图直接拖动封面，不再显示左上角六点手柄。两种视图都支持多选后成组拖动：拖动任意已选作品，当前可见的已选作品会按页面顺序整体移动，连续或不连续多选均可；拖动未选作品时只移动该作品。移动过程中显示位置动画；缩略图的蓝色插入指示线显示在目标卡片左侧或右侧接缝，列表则显示在目标行上方或下方。松开后保存，Esc取消并恢复原顺序及选择；拖动结束产生的点击不会误切换选中状态。筛选时仅重排可见作品，隐藏作品保留原来的位置；手动顺序会持久保存，发布后同步到展示站。缩略图在触屏上保留纵向页面滑动。
- **作品卡片和菜单**：缩略图封面铺满网格，左下角始终显示标签小字及作品标题，右下角显示状态，右上角编辑按钮保留半透明玻璃背景、细边框和背景模糊，并增加轻淡投影，点击打开作品编辑浮层。左上角只显示复选框本身，外层不添加玻璃背景、边框、模糊或投影，保留便于点击的范围；悬停或键盘聚焦时显示；勾选后进入多选模式，其他复选框保持显示，也可直接点击封面加选或取消选择。列表与缩略图切换时保留选择，点击批量操作栏的「取消选择」退出多选模式。触屏上复选框常显。列表三点菜单可再次点击三点或点击菜单外区域关闭。
- **标签管理**：顶部统一维护作品标签，点击「+」后直接在标签位置输入名称；双击已有标签可原位修改名称。输入框右侧显示对号，点击即可完成输入；也可回车或失焦保存，Esc取消，空名称取消。输入框与对号之间切换焦点不会提前保存；同名冲突在输入处提示，不弹窗。悬停显示居中的圆形删除按钮，点击直接删除，无确认窗口。改名同步更新相关作品草稿中的标签，删除只移除相应草稿标签，保留作品内容、其他标签和已发布版本；发布相关修改后同步到展示站。初始保留「品牌 / IP、包装设计、UI / UX、平面视觉、空间设计、电商视觉」六项，以后仍可添加、改名或删除。
- **展示设置**：合并为一个页面，去掉四个二级菜单与无可编辑内容的「外观细节」，依次展示「首页背景」「个人信息」「网站信息与页脚」三个分区。姓名、职业身份、介绍与联系方式统一维护。顶部「预览」「保存设置」随页面滚动吸顶，统一预览、保存整页设置；保存先进入草稿，发布时勾选「同时发布网站设置」后生效。旧标识、标题文字、技能与外观字段保留数据兼容，当前页面不再展示对应控件。
- **发布网站**：只更新勾选的作品及网站设置，其余已发布内容保持原版；失败保留上次成功版本。
- **发布记录**：查看历史版本、恢复历史版本、下载部署ZIP和源文件ZIP。顶部「自动保留」可选择最近5条或10条，默认10条，数量包含当前版本；切换数量后立即清理超出的较早版本，之后每次发布成功或恢复版本成功后自动执行同一规则。恢复会产生新记录，当前编辑草稿保留。
- **回收站**：已发布作品先下架再移入回收站，恢复后为草稿。
- **素材库**：未被作品或历史发布版本引用的素材可永久删除；被引用的素材保留，以保证作品及历史版本可恢复。

### 3.1 素材文件夹、视图、选择与预览

素材库与编辑作品中的「上传或选择媒体」窗口共用同一份文件夹、媒体归属和手动排序数据；以下功能在两个入口均可使用。各自在当前浏览期间保留位置、视图、缩略图大小、列表预览开关与筛选状态，这些界面偏好不写入素材或作品数据。

- **创建与导航**：素材库顶部「上传素材」左侧、选择窗口底部「上传新媒体」旁均有「创建文件夹」。直接输入文件夹名称，回车或点击对号创建，Esc取消。支持嵌套文件夹，点击文件夹进入，面包屑返回上级或全部素材；同一父目录不允许重名。
- **文件夹优先**：缩略图和列表视图都始终先显示文件夹、再显示媒体。可以筛选「显示全部」「仅显示文件夹」「仅显示媒体」，并在当前目录搜索文件名或文件夹名。选择窗口仍遵守图片、视频、音频的类型筛选。
- **上传位置与层级**：上传普通媒体时放入当前文件夹。点击「上传文件夹」使用浏览器目录选择器，按文件的相对路径还原顶层及子文件夹；重复导入时复用已有的同名目录。浏览器未提供的空目录无法还原。不支持的文件、超过大小限制或不符合当前选择类型的文件会跳过并提示。
- **直接上传**：点击「上传素材／上传新媒体」直接打开系统文件选择窗口，媒体保存到当前目录；需要归类时可先进入文件夹再上传，或上传后拖动归类。「上传文件夹」继续保留目录层级。编辑窗口上传时保留原媒体选择窗口、暂存规则和选用回调。
- **拖动排序**：两种视图、两个入口均可拖动媒体或文件夹排序，蓝线标明目标插入位置。文件夹与媒体各自在同类项目中排序；从属性排序视图拖动后切回手动排序。顺序写入数据库，重新打开仍保留。
- **拖入归类**：将媒体拖到文件夹可移入，将文件夹拖到另一文件夹中央可嵌套；拖到文件夹边缘可调整同级文件夹顺序。将项目拖到面包屑可移到上级或根目录。文件夹高亮表示移入目标，禁止移入自身、子文件夹或存在同名文件夹的目标目录。Esc取消拖动。
- **列表属性排序**：列表显示文件名、类型、大小、上传时间、图片尺寸；点击文件名、类型、大小或上传时间可排序，再次点击倒序，文件夹始终在前。列表中的媒体同样支持选择和拖动。
- **缩略图尺寸**：文件夹与媒体卡片统一为4:3比例，文件夹名称和数量放在卡片内，不额外增加高度。视图切换图标左侧提供大小滑杆，可实时调整缩略图大小；网格随容器宽度自动换行，切换视图、筛选和进入文件夹时保留当前大小。两个素材入口分别保留各自的大小设置。
- **列表预览**：列表模式的视图图标左侧提供「列表预览」开关。开启后隐藏类型、大小、上传时间等属性列，以小图标和文件名从左到右排列，一行多个文件，向下延伸；关闭后恢复带属性的详细列表。两种列表均保留文件夹导航、全选、多选、批量拖动、归类和独立预览；预览列表仍可通过上方排序选项排序。
- **多选与批量移动**：两个入口均支持素材和文件夹多选。缩略图左上角的复选框悬停／键盘聚焦时显示，进入多选模式后保持显示；触屏上常显。复选框无外层玻璃背景。列表最左侧为复选框，表头可全选当前筛选结果。选择在视图切换和文件夹导航之间保留，操作栏显示数量并提供全选、取消选择。拖动任意已选项目会整体移动；当前视图内按页面顺序排列，其他目录的已选项目一并归类，文件夹始终在媒体前面。
- **多选点击规则**：点击任意复选框后进入多选模式，此时再点击素材封面或列表媒体行会加选／取消对应素材，不打开独立预览。取消全部选择后恢复点击预览。两种视图、两个入口采用同一规则，编辑窗口中也同步维护用于正文插入或封面的媒体选择。
- **Shift 连选**：进入多选模式后，按住 Shift 点击素材、文件夹或其复选框，会按当前目录、筛选和排序选中从上一次普通点击项到本次点击项之间的全部可见项目，同时保留原有选择。连续 Shift 点击沿用同一起点；普通点击会更新起点。起点不在当前结果中时，只选中本次点击项，不跨目录或隐藏结果扩选。缩略图、详细列表及列表预览均支持；封面选择窗口仍只使用最后点击的素材作为封面。
- **连选操作示例**：先勾选第2项，再按住 Shift 点击第5项，会选中第2～5项；随后普通点击第7项可加选并更新起点，再按住 Shift 点击第9项，会追加第7～9项。向前点击也可以反向连选。Shift 点击文件夹卡片用于连选，普通点击文件夹仍用于进入目录。
- **删除所选**：多选操作栏提供「删除所选」，先统计所选文件夹及其全部子目录、媒体，再确认永久删除。重叠选择会去重，按子目录先于父目录的顺序删除；媒体文件及暂存关联一并移除。只要包含被作品草稿、已发布内容或历史版本引用的素材，整组就不能删除并显示原因，所有所选项目保持不变，避免部分删除。
- **批量保护**：整组移动一次提交，任意项目失效、同名文件夹冲突或循环嵌套都会取消整组移动，防止部分移动。父文件夹和其中的子项同时选中时，子项随父文件夹移动并保留原层级；Esc取消拖动不改变位置或选择。
- **缩略图信息排版**：图片／视频封面撑满卡片，左下角为文件名，文件名上方以小字显示图片尺寸或媒体类型，右下角为文件大小；引用信息或暂存状态放在右上角。底部使用固定高度的渐变遮罩提升可读性。选择状态以卡片内的浅蓝覆盖与复选框表示。
- **独立媒体预览**：未处于多选模式时，点击缩略图或列表媒体行打开独立预览，图片保持完整比例，视频／音频可播放。预览内容宽度收至最多1180像素、图片区域约屏幕高度的三分之二；点击空白处、右上角关闭或Esc可返回，空格不执行退出操作。滚轮围绕鼠标位置缩放图片（25%～600%），鼠标左键拖动查看，拖动结束不会误触空白关闭。左右方向键按当前目录和当前排序切换图片，并重置缩放与位置。预览位于原媒体选择窗口上方，关闭后保留原窗口、位置和选择，不退出作品编辑器。
- **选择与暂存**：在选择窗口跨文件夹选取、归类或切换视图后，已选媒体及原本的插入／封面回调会保留。作品编辑中上传的媒体仍为暂存，发布作品后才进入素材库；在素材库直接上传的文件立即入库。创建目录或移动项目不会提前将暂存媒体入库。
- **预览与选用分开**：非多选状态下点击媒体用于预览，勾选复选框进入选择状态；预览中也提供「选择此媒体」。插入正文时可使用多个已选媒体，文件夹只用于管理、不作为正文块插入。设置封面时仍只使用一项媒体：批量管理可多选，封面取最后勾选或在预览中选用的一项，取消该项后回退到剩余最后一项。
- **引用与兼容**：目录为逻辑分组，移动不会改变媒体编号、文件地址、作品正文引用或已发布版本。旧素材自动归入根目录，现有作品无需重传媒体。同一目录内相同内容沿用去重机制；相同内容上传到不同目录时建立独立素材条目，保留各自归属。

### 3.2 首页背景媒体

- 进入「展示设置」即可看到首页背景分区，无需切换二级菜单。「上传媒体」支持一次选择图片和视频；素材库选择窗口同样同时展示图片与视频，不接受音频。支持PNG／JPEG／WebP／GIF图片及MP4／WebM视频，上传的背景素材立即进入素材库。默认包含当前彩墨视频。
- **静态缩略图**：视频列表左侧仅显示静态首帧，没有播放控件。后台用隐藏的解码元素提取首帧，完成后立即释放；首帧在当前管理页面会话中按视频地址缓存，排序或修改其他设置时沿用，不写入素材库或发布配置。无法提取时显示「首帧暂不可用」。图片直接显示缩略图。
- **在素材库显示**：已入库素材的缩略图右上角提供定位按钮，点击后打开素材所在文件夹，清除搜索、类型与未使用筛选，滚动定位并短暂高亮；支持缩略图、详细列表和列表预览，不进入多选模式。内置默认视频没有素材条目，因此不显示该定位按钮。定位离开设置页同样遵守未保存检查，取消离开时保留当前设置输入。
- 黑色蒙板提供滑块和百分比输入框，0～100%整数、默认80%。拖动时数值同步且不重建控件；0%无遮罩、100%纯黑，文字与按钮不受影响。未设置过蒙板的旧数据自动采用80%，保存、预览、发布及部署包均携带homeBackground.shadeOpacity；预览不覆盖设置草稿。
- 列表从左至右为带顺序编号的六点控制手柄、缩略图、文件名称、播放速度／图片停留时长、移除按钮。取消「上移／下移」，拖动时显示跟随鼠标的缩略条目与「原位置 → 目标位置」编号，相邻条目平滑让位、编号同步更新，松开后条目落位；蓝线提示目标接缝，靠近视口边缘可自动滚动。Esc、指针取消或窗口失焦取消拖动并恢复顺序与编号；聚焦手柄后也可按上下方向键调整。减少动态效果时跳过位移动画。排序暂存在设置草稿，保存后持久化，发布后按该顺序展示；移除播放项不删除素材文件。
- 视频速度可设0.25～4倍；图片默认停留5秒，可设1～120秒。图片和视频合计最多30项。速度、时长、数量及发布操作提示位于媒体列表正下方、结束定格帧区域上方。沿用homeBackground.videos数组兼容旧设置，图片条目携带type:image与duration，视频仍使用playbackRate。
- 「结束定格帧」可上传或选择图片，也可移除。全部媒体展示结束后，有设置图片则显示该图，否则保留最后的图片或视频最后一帧；空列表仅显示静态图／定格图。不自动循环，观众主动点击空白处可以从头重播。
- 前台用两个视频层提前加载下一条，下一段首帧可显示后再替换画面，切换等待时保留前一画面。各段内容本身的视觉衔接取决于上传视频；不会靠黑场等待加载。视频无法播放时跳过，全部失败保留可用画面或静态图。
- 图片与视频可混排，图片加载完成后再替换上一画面，并预加载下一项。暂停、离屏或切后台时暂停图片倒计时，恢复后只继续剩余时长；图片加载失败自动跳过。减少动态效果时使用列表中的静态图片，不播放视频或启动倒计时。图片与视频同样受设置草稿、当前发布及历史记录的素材引用保护，预览、发布与导出均包含其相对路径配置及文件。
- 取消左上品牌胶囊和右下暂停按钮；点击首页空白处暂停／继续，点击标题、介绍、链接和按钮不会触发。键盘聚焦首屏后可按空格／回车。离屏、切后台或打开作品浮层暂停，返回时保留用户暂停选择；减少动态效果时不加载视频。
- 首页视频叠加80%不透明黑色蒙板；不显示可见标题；下方为半透明黑色长条中的四个直角按钮，介绍文案紧随其下，并预留底部空隙。窄屏自然换行，小屏四个按钮为2×2排列。视频背景全宽，作品区单独居中，最大宽度1620px、两侧20～44px响应式留白，分类吸顶保留。
- 保存后先写设置草稿，预览可查看未发布效果；发布时勾选网站设置才更新「查看站点」。发布与源文件ZIP均包含视频、结束图片与相对路径配置，不依赖后台私有素材地址，也不自动覆盖独立作品站源文件夹。
- 视频和定格图被设置草稿、当前发布或历史发布引用时受删除保护；取消当前设置不会破坏旧版本恢复。发布只更新首页设置也可以，不必重新发布所有作品。
- 本轮按用户要求同步后台发布模板首页，保留其原有多标签、音视频与富文本正文功能。`original-integrity.json` 基线在这次明确授权的独立站首页修改后重新记录；以后仍检查后台运行没有修改该独立站。

### 3.3 个人信息、网站信息与页脚

- 「个人信息」按首页介绍、姓名与职业身份、联系方式的顺序排列。介绍、姓名与身份显示在首页按钮栏下方；微信、Bilibili昵称及主要邮箱显示在首页按钮栏与页脚，备用邮箱不在首页显示。
- 「网站信息与页脚」设置浏览器页面标题、网站描述及页脚信息。页面标题用于浏览器标签；描述写入网页元信息，不在正文显示，搜索引擎自行决定搜索摘要。移除单独的「作品集年份」控件，原「页脚注册信息」分组改为「页脚信息」，新增可直接编辑的多行文字框，当前默认内容为「© 2026 噼哩画啦 · 作品集」。旧设置未包含页脚文字时沿用原年份与姓名生成初始值；保存后使用独立的footer.text，不再随姓名或年份自动拼接。支持纯文本换行，最多1000字符，留空时隐藏该段；预览、发布及导出使用同一内容。备案／注册文字与HTTPS链接仍为可选项，留空时隐藏。旧年份数据保留兼容历史版本。
- 三个分区始终在同一页展示，修改文字和联系方式后再调整视频顺序或定格图，尚未保存的输入仍保留；顶部统一保存，不需要逐区提交。「预览」包含当前整页未发布修改，不覆盖已保存草稿。
- 离开有实际修改的设置页时，弹窗按顺序提供下列三个按钮；重复点击当前导航不视为离开。

| 按钮 | 行为 |
| --- | --- |
| 取消 | 留在设置页，保留当前输入 |
| 离开 | 丢弃尚未保存的修改，前往目标页面 |
| 保存设置并离开 | 先保存为设置草稿，成功后离开；失败则留在设置页并保留输入 |

- 未保存状态通过当前内容与最近保存的基线比较，忽略与服务端相同的首尾空白规范化及兼容默认值；只触发输入事件、改回原值或刚保存后离开不误弹窗。保存时使用提交瞬间的快照，服务端返回实际保存内容作为新基线；请求期间新增的输入仍被视为未保存。保存过程中按钮显示「保存中…」，离开会等待当前请求结束，再检查是否还有未保存修改。
- 网站的白色作品区、直角封面及标签、黑底白字的选中分类和四个首页入口的顺序、颜色由模板统一维护，不再占用一个设置菜单。

## 4. 发布、部署与使用范围

后台中的「发布」更新本机独立的[展示副本](http://127.0.0.1:4180/site/)，未连接阿里云、腾讯云或其他远程账号。

右上角「发布与导出」确认后更新本机展示副本，完成窗口可下载部署包，也可在发布记录中下载。ZIP根目录为网站的HTML、样式、脚本、图片和作品数据，可按托管平台要求上传。源文件包保留 `Portfolio/作品名称/index.md` 及媒体，安装依赖后可执行 `npm run build` 重新构建。

### 4.1 从部署包恢复到后台

2026-10-26起新生成的部署包携带 `assets/home/portfolio-restore.json`，包含该版本已发布作品的原始内容块、排序、标签、简介、有效封面取景，以及网站设置和所用媒体的对应信息。源文件包也包含相同描述。编辑数据随静态网站公开，请只发布可公开的内容；包内不包含数据库或后台服务代码。

使用流程：

1. 原电脑通过「发布与导出」生成并下载新的部署ZIP，单独保留一份。
2. 在另一台电脑安装并启动后台，直接进入作品管理。
3. 点击「导入项目」→「选择部署ZIP」，查看网站名称、作品与素材数量、同编号作品清单。
4. 点击「确认导入到草稿」，检查、修改后再发布、导出部署包，上传到云平台。

导入规则：

- 新作品作为草稿加入；已有同编号作品替换其草稿，保留当前已发布内容。其他作品与素材不会被清空。回收站中的同编号作品恢复为草稿。
- 网站设置恢复为设置草稿，保留本机额外的分类标签；当前展示站、已发布设置、发布历史和历史保留数量不改变。
- 所用素材恢复到素材库，保留文件夹名称与层级；同一文件夹内内容相同的素材重用。本机素材编号重新对应，作品与背景引用一并修复。
- 导入前校验ZIP、描述版本、媒体类型、大小及内容哈希；不执行部署包中的网页或脚本。导入失败撤销数据库修改并清理本次写入的媒体。预览后相关作品或设置发生变化时，拒绝覆盖，需重新预览确认。
- 导入ZIP及解压内容总量均限512 MB；单张图片限30 MB，音视频限200 MB，最多300个作品、5000项所用素材。不支持加密包或ZIP64。
- 取消导入会删除暂存ZIP；未完成的临时包在一小时后于下次检查导入包时清理。重启后需重新选择部署包。
- 旧部署包没有恢复描述，不能直接恢复为编辑数据；需用新版后台重新发布并下载。云平台不一定提供完整部署包下载，请保留自己的ZIP副本；不要把「保存网页」得到的文件当成部署包。

部署包仅恢复该版本**已发布**内容，不包含未发布草稿、未使用素材、空文件夹、未启用的旧独立封面、回收站及历史记录，不能代替第5节的完整备份。本次未加入完整私有项目包导入导出或空白初始化功能。

后台需要Node.js服务，不能仅将后台文件夹作为静态HTML压缩包上传使用。当前服务仅监听本机 `127.0.0.1`，手机不能直接访问电脑的这个地址。

当前没有多人协作、PDF解析、远程云端直传或自动部署功能。展示副本采用首页图片／视频背景，保留作品标签吸顶、作品瀑布流、详情浮层和图片放大等展示交互。

## 5. 数据位置与备份

运行数据默认位于Windows用户数据目录，启动时会打印完整路径：

```text
%LOCALAPPDATA%/PixixPortfolioAdmin/<本项目路径对应的标识>/
├── portfolio.sqlite      作品、草稿、设置与发布记录
├── uploads/              上传及导入的原始媒体
├── releases/             发布版本及对应源文件、部署文件
├── previews/             私有草稿预览
├── imports/              待确认的导入ZIP（临时）
└── jobs/                 构建中的文件与失败任务
```

数据放在项目目录之外，避免被其他静态预览服务器作为普通文件公开。发布历史按保留数量自动清理；预览缓存、失败任务和素材原件不在该规则内，仍需要按使用情况管理空间与备份。

### 5.1 发布历史自动保留规则

- 保留策略是后台自己的管理设置，以releaseRetention单独持久化，默认10条，可选5条；不作为网站展示设置发布，回退网站版本也不改变该策略。
- 优先保留近期成功发布记录，并始终保留当前线上版本；即使当前版本不在最近几条中，也计入保留数量。生成预览或发布过程中不能修改策略，防止与正在使用的版本发生冲突。
- 清理同时移除过期记录及其完整发布目录，包含源文件、部署副本与快照；删除后不能继续查看、下载或回退该版本。当前线上版本、作品草稿和素材库原件保留。已清理版本不再占用素材的历史引用，若素材没有其他引用，可在素材库另行删除。
- 仅在新版本构建、发布成功后自动清理，构建失败不清理现有历史。清理先将旧目录移入运行数据目录内的.release-cleanup暂存区，再提交记录删除；数据库提交失败会将目录移回。中断重启时恢复尚未提交的目录，重试删除已提交的过期文件。清理异常不回退已经成功发布的新版本，界面提示后续重试。
- 目录删除限制在后台运行数据范围内，不跟随发布目录内部的依赖链接删除外部文件。完整备份应包括仍存在的.release-cleanup目录，以保留中断恢复能力。
- 本规则仅作用于本机后台发布历史，未连接腾讯／阿里云的部署记录或GitHub提交历史；将来接入云端自动部署时，需要另行同步平台侧的清理规则。

完整备份时先停止后台服务，再复制整个运行数据目录，并同时保存项目代码。不要只复制SQLite主文件或正在写入的文件。恢复时放回完整数据目录再启动。

移动项目位置会改变默认数据标识，可通过环境变量指向原数据目录。示例：

```powershell
$env:PORTFOLIO_DATA_DIR = 'C:\Users\你的用户名\AppData\Local\PortfolioData'
$env:PORT = '4180'
npm start
```

自定义数据目录也应放在不会被静态服务器公开的位置。

- `renderer`用于初始化及生成展示站。已导入的作品以数据库为准，手动修改模板中的 `Portfolio` 不会覆盖数据库内容。
